# 总结与展望写法（中文学术）

目标：**回顾贡献**，**陈述局限**，**指明方向**——不引入新论点。

## 推荐结构（6-10句）

### 总结部分

1. **一句话**：本文做了什么（系统/方法/基准）
2. **一句话**：核心技术思路
3. **1-2句**：主要实验结果（可带数字）
4. **1-2句**：意义（本工作为该领域提供了什么）

### 展望部分

5. **1-2句**：局限性（具体的，非泛泛）
6. **1-2句**：未来工作方向（与局限性对应）

## 写作原则

### 不要

- 不引入新的实验结果或新方法
- 不重复绪论的背景段
- 不做过度声称（"本文彻底解决了……"）

### 要

- 贡献点与绪论中的贡献列表一一对应
- 局限性要具体："本文仅评测了C++语言" 而非 "有待进一步研究"
- 未来方向要可操作："后续可扩展到多语言评测" 而非 "可做更多工作"

## 模板

> 本文设计并实现了一套面向交互算法题的大语言模型评测系统。该系统通过……实现了……。基于322道交互算法题对N个主流模型的评测实验表明，……。本工作为系统性地评测LLM解决交互问题的能力提供了工具支撑。
>
> 本文的工作仍存在以下局限：(1) 评测仅覆盖C++语言，尚未扩展到其他编程语言；(2) ……。未来工作将从以下方面展开：(1) ……；(2) ……。

## 中文学位论文注意

- 章标题"N 总结与展望"（或"结论"），黑体小2号加粗居中
- 篇幅适中：1-2页
- 在总结章之后是"参考文献"，不再有正文内容

## 自查清单

- [ ] 贡献回顾与绪论中的贡献列表一致
- [ ] 有至少一个具体的定量结果
- [ ] 局限性具体、非泛泛
- [ ] 未来方向与局限性对应
- [ ] 无新论点、新数据
- [ ] 篇幅适中（1-2页）
