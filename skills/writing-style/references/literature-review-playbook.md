# 文献综述写法（中文学术）

目标：展示对领域的全面理解，证明本文贡献的**独特性**。

## 与绪论的关系

- 绪论中已简要提及相关工作 → 综述章做深入展开
- 中文学位论文通常将文献综述放在绪论内（1.2节左右），或独立成章（第2章）
- 无论哪种方式，内容组织逻辑相同

## 推荐结构

### 1) 框架句

开篇1-2句说明综述的组织方式：

> 本节从以下三个方面综述相关工作：（1）LLM代码生成评测基准的演进；（2）竞赛编程评测基准与交互算法题；（3）发展趋势与本课题定位。

### 2) 按主题分节（非按时间罗列）

每节聚焦一个主题，典型结构：

1. **主题概述**（1-2句）
2. **代表性工作介绍**（按逻辑关系，非简单列举）
3. **与本文的关系**（该主题下本文的定位）

### 3) 最接近工作的直接对比

单独用一段或一表直接比较：

| 特征 | 工作A | 工作B | 工作C | 本文 |
|------|-------|-------|-------|------|
| 特征1 | ✓ | ✓ | ✗ | ✓ |
| 特征2 | ✗ | ✓ | ✓ | ✓ |
| … | … | … | … | … |

### 4) 综述小结

1-2句总结现有工作的共同不足，自然引出本文的必要性。

## 写作策略

### 引用策略

- 用简短的比较句：
  - "X等[n]关注……，而Y等[m]则侧重……"
  - "与X[n]不同，本文……"
  - "X[n]假设……；本文放宽了这一假设"
- 避免引用堆砌："已有许多工作研究该问题[1-30]"
  - 替换为：引2-6篇代表性工作并分类讨论

### 叙述式 vs 注释式

- **叙述式**（作者是主语）："杨泽洲等[13]系统综述了基于深度学习的代码生成方法"
- **注释式**（工作是补充说明）："近年来，多项工作关注LLM代码生成评测[1,3-5]"
- 两种句式交替使用，避免单调

### 国内文献的融入

中文学位论文建议引用国内学者的工作：
- 与英文文献同等地位，按主题归类
- 格式："杨泽洲等[13]" / "Wang等[17]"
- 不要单独开一节"国内研究"——按主题混编更自然

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 只列举不比较 | 每段至少一个比较句 |
| 与本文的区别不清 | 每节末尾点明本文的不同之处 |
| 文献覆盖不全 | 检查近3年高引工作是否涵盖 |
| 时间线叙述冗长 | 改为按主题组织 |
| 评价过于主观 | 用客观描述："X关注……而未涉及……" |

## 自查清单

- [ ] 按主题（非按时间）组织
- [ ] 最接近的工作被直接比较
- [ ] 每节末尾有与本文的关联
- [ ] 引用不堆砌，每处2-6篇代表性工作
- [ ] 国内外文献按主题混编
- [ ] 综述结尾自然过渡到本文的方法/设计
- [ ] 近3年文献比例≥30%（学位论文常见要求）
