# 图表规范

## 一、表格写作规范

### Caption 自包含

表标题应让读者不看正文也能理解表的内容：

**好的 caption：**
> 31 个大语言模型在 322 道交互算法题上的 pass@k 评测结果（k=1,10）

**差的 caption：**
> 实验结果

### 表格设计

- 使用三线表（booktabs 风格：顶线、栏线、底线），避免满格线和竖线
- 最佳结果**加粗**；如需高亮最差结果，使用灰色底纹
- 表注放在表格下方，说明缩写和特殊标记
- 指标名标明方向（如 `Accuracy ↑`、`Error ↓`），需要时给出单位
- 同一指标列保持相同小数位与数字对齐方式
- 一张表只承担一个主要信息；不同问题拆成独立表格或清楚分组

### 正文引用

- 每张表在正文中必须被引用，先出现引用再出现表格（或同页）

## 二、图的写作规范

### 类型选择

| 目的 | 推荐图类型 |
|------|-----------|
| 系统架构/流程 | 架构图/流程图 |
| 数据对比 | 柱状图/折线图 |
| 组成比例 | 饼图（少用）/ 堆叠柱状图 |
| 分布 | 箱线图/直方图 |
| 交互过程 | 时序图/交互示意图 |

### 全局架构图

- 通常出现在 Method 章开头，展示模块组成和数据流向
- 是全文的"锚点图"，在 Introduction 中提及

### 图的质量要求

- 分辨率足够，缩放后文字清晰
- 用色适度，黑白打印也能区分
- 图中文字与正文语言一致，英文缩写可保留

### 正文引用

- 与表格相同：先引用再出现

## 三、公式规范

- 公式居中；变量用斜体，函数名用正体
- 公式前后有文字衔接，不要公式独立出现
- 符号定义与记号约定详见 `equations-and-notation.md`

## 四、自查清单

- [ ] 每张图表在正文中被引用，先引用后出现
- [ ] Caption 自包含
- [ ] 三线表格式，最佳结果加粗
- [ ] 图在黑白打印下可识别
- [ ] 公式有文字衔接，符号首次使用处有定义
