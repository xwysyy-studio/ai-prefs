# 图表规范（中文学术）

## 一、中文学位论文格式要求

### 表格

- **表标题位于表上方**
- 标题字体：黑体小4号
- 数字/字母：Times New Roman 小4号
- 表内容：宋体5号，数字/字母 Times New Roman 5号
- 标题居中
- **标题和表必须在同一页**

### 图

- **图标题位于图下方**
- 标题字体：黑体小4号
- 数字/字母：Times New Roman 小4号
- **标题和图必须在同一页**

### 编号格式

- 图编号：图X-Y（X为章号，Y为图序号），如"图3-1"
- 表编号：表X-Y，如"表5-1"
- 公式编号：(X-Y)，如"(3-1)"

## 二、表格写作规范

### Caption 自包含

表标题应让读者不看正文也能理解表的内容：

**好的 caption：**
> 表5-1 31个大语言模型在322道交互算法题上的 pass@k 评测结果（k=1,10）

**差的 caption：**
> 表5-1 实验结果

### 表格设计

- 使用三线表（顶线、栏线、底线），避免满格线
- 最佳结果**加粗**
- 如需高亮最差结果，使用灰色底纹
- 表注放在表格下方，说明缩写和特殊标记

### 正文引用

- 每张表在正文中必须被引用
- 先出现引用，再出现表格（或同页）
- 引用格式："如表5-1所示" / "表5-1展示了……"

## 三、图的写作规范

### 类型选择

| 目的 | 推荐图类型 |
|------|-----------|
| 系统架构/流程 | 架构图/流程图 |
| 数据对比 | 柱状图/折线图 |
| 组成比例 | 饼图（少用）/ 堆叠柱状图 |
| 分布 | 箱线图/直方图 |
| 交互过程 | 时序图/交互示意图 |

### 全局架构图（图1 或 图3-1）

- 通常出现在系统设计章的开头
- 展示模块组成和数据流向
- 是全文的"锚点图"，在绪论中提及

### 图的质量要求

- 分辨率足够，缩放后文字清晰
- 用色适度，黑白打印也能区分
- 图中文字使用中文（与正文一致），英文缩写可保留

### 正文引用

- 与表格相同：先引用再出现
- 格式："如图3-1所示" / "图3-1展示了……"

## 四、公式规范

- 公式居中，编号右对齐
- 编号格式：(章号-序号)
- 公式中的变量用斜体，函数名用正体
- 公式前后有文字衔接，不要公式独立出现

## 五、自查清单

- [ ] 表标题在表上方，图标题在图下方
- [ ] 标题字体：黑体小4号
- [ ] 编号格式：图X-Y / 表X-Y / (X-Y)
- [ ] 每张图表在正文中被引用
- [ ] 标题和图表在同一页
- [ ] Caption 自包含
- [ ] 三线表格式，最佳结果加粗
- [ ] 图在黑白打印下可识别
