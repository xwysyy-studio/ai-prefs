# Abstract 写法（top venue）

英文 top-venue 摘要先找**承重句**：一句改变读者理解的话，其余句子都为它铺路。承重句由论文的核心概念动作决定，弧线随之变化：

- Technique paper：从结构瓶颈走到 key insight
- Benchmark paper：从缺失维度走到它揭示的新发现
- Claim-testing paper：先点名待检验的主张，再介绍把争论变成可测对象的 probe
- Simplification paper：提出一个能力问题，再说明哪些复杂步骤因此变得多余

铺路句从五个功能里按需取：task 与重要性、gap 一句话、为什么难、核心方法一句话、承重结果加有界结论。功能可以合并，篇幅向承重句倾斜。读者应在结果出现前理解本文改变了什么；empirical/benchmark 论文保留让 central takeaway 更可信的一两个数字（至少一个），其余留正文；理论/定性论文给可指认的定性结论。

贡献句点名核心技术或 insight 及其直接作用即可。实现步骤和模块关系留给 Method，摘要保持一遍读懂的连续弧线。

默认不引用文献。benchmark paper 的 results 侧重"揭示了什么发现"，胜过"超过 baseline 多少"。

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 背景过多，贡献过少 | 背景限制在 1-2 句，贡献与结果占主体 |
| 只说做了什么，不说结果 | 给出承重结果：empirical 论文用具体数字，理论/定性论文用可指认的结论 |
| 罗列所有工作而非聚焦 | 只写 1-2 个核心贡献 |
| gap 不明显 | 用一句明确转折点出现有工作缺什么 |
| 论断过强 | 有界表述，数字旁置 |

## 自查清单

- [ ] 承重句存在且可指认
- [ ] 包含问题、方法、结果三要素
- [ ] empirical/benchmark 论文至少一个具体数字；理论/定性论文有可指认的定性结论
- [ ] 单段，无引用标记
- [ ] 论断有界，无过度声称
