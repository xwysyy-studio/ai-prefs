# 终审检查清单（中文学术）

提交前逐项检查。每类标注 [ ] 表示待检查，[x] 表示已通过。

## 一、论文结构

- [ ] 11部分结构完整且顺序正确（封面→声明→摘要→目录→正文→参考文献→附录→致谢→任务书→评定表→封底）
- [ ] 封面用120g白色铜版纸
- [ ] 原创性声明和版权授权书已签名
- [ ] 中英文摘要各一，均有关键词
- [ ] 目录层级正确，页码对应

## 二、摘要与关键词

- [ ] 中文摘要包含：问题+方法+结果+意义
- [ ] 有至少一个具体数字或定量描述
- [ ] 关键词3-5个，中英文一一对应
- [ ] 摘要中无引用标记
- [ ] 英文摘要与中文内容对应（非逐字翻译）

## 三、绪论与贡献

- [ ] 研究背景具体，不泛泛
- [ ] Gap 句显眼，用"然而"/"但"转折
- [ ] 贡献明确列出（编号格式）
- [ ] 贡献数量2-4个
- [ ] 每个贡献在实验章有对应验证
- [ ] 论文结构路线图存在

## 四、正文质量

- [ ] 人称一致："本文"/"本工作"/"本研究"/"本课题"，无"我"/"我们"
- [ ] 术语首次出现时给出英文全称+缩写
- [ ] 全文术语一致，无近义词交替
- [ ] "评测/评估/测试"语义分工正确："评测"用于模型能力与题目判定，"测试"仅用于系统测试
- [ ] 核心术语与 `terminology-and-citation.md` 固定术语表一致，无混用（如"评测系统"vs"评测引擎"vs"评测器"）
- [ ] 每段有总领句
- [ ] 每章（除绪论/结论）有引言段
- [ ] 章间有过渡
- [ ] 无孤儿段
- [ ] 论断有界，无过度声称
- [ ] 无连续三句以相同主语/句式开头（"三连同构"）
- [ ] 数据结论段有"观察→数字→解读"的节奏
- [ ] 关键学术表达多样化，避免全文重复同一句式

## 五、实验与数据

- [ ] 实验设置完整（数据+指标+基线+配置）
- [ ] 主结果表存在且格式规范
- [ ] 有分析（消融/失败/敏感性中至少一种）
- [ ] 结果描述措辞与证据强度匹配
- [ ] 负面结果被诚实报告
- [ ] 局限性被具体说明

## 六、引用与参考文献

- [ ] 引用格式统一 [数字]
- [ ] 叙述式/注释式搭配使用
- [ ] 无引用堆砌
- [ ] 最接近工作被引用并比较
- [ ] 参考文献格式符合 GB/T 7714
- [ ] **近3年文献比例≥30%**（学位论文常见要求）
- [ ] 引用过的arXiv论文检查是否已正式发表并更新

## 七、图表与公式

- [ ] 表标题在表上方，图标题在图下方
- [ ] 标题字体：黑体小4号
- [ ] 编号格式：图X-Y / 表X-Y / (X-Y)
- [ ] 每张图表在正文中被引用
- [ ] 标题和图表在同一页
- [ ] Caption 自包含
- [ ] 公式符号定义在首次使用处

## 八、格式与排版（格式规范（按目标学校/venue））

- [ ] 章标题：黑体小2号加粗居中
- [ ] 节标题：黑体4号加粗
- [ ] 小节标题：黑体小4号加粗
- [ ] 正文：宋体小4号，固定1.5倍行距
- [ ] 字符间距：标准（摘要/正文，按附件1.2格式示例）
- [ ] 数字/字母：Times New Roman 对应字号
- [ ] 中文全角标点，英文/公式半角标点
- [ ] 章间分页符
- [ ] 页眉：按目标学校要求设置

## 九、查重与学术诚信

- [ ] 查重工具：turnitin
- [ ] 查重率：A级(≤15%)通过 / B级(15-20%)需导师审核 / C级(>20%)不通过
- [ ] 按学院工作方案：C级不通过且不能参加答辩；不合格需修改复检后方可申请答辩
- [ ] 大段引用已改写为自己的表述
- [ ] 所有引用文献真实存在（可通过 Semantic Scholar/Google Scholar 验证）
- [ ] 图表如来自他人工作，已标注来源

## 十、总结与致谢

- [ ] 总结章贡献回顾与绪论贡献列表一致
- [ ] 有具体局限性和未来方向
- [ ] 致谢内容适当（导师、同学、资助等）
- [ ] 无新论点出现在总结章
