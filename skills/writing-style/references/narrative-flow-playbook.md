# 叙事逻辑 Playbook（承重因果链）

本 playbook 提供学术论文在**论文级与段落级**的叙事结构指导：内核是一条承重因果链，外部结构由目标 venue 的体裁惯例决定，内部逻辑始终由承重链决定。

真实研究通常从观察、想法、实验和结果之间反复迭代。论文按照成熟后的认识组织：先从实际材料与结果中确定最有价值且证据最稳的中心主张，再反向确定核心概念、Introduction 的问题位置、Method 的解释顺序和 Experiments 的呈现顺序。其余主张只有在推进这条主线时才进入正文。

中心主张必须随证据更新。结果只是缩窄成立范围时，收窄 claim；结果实质推翻中心主张时，停止沿原故事润色，交用户重选中心主张或重构故事，并保留对核心判断有实质影响的反证。结果产生后新增的评价维度或数据只能作为透明标注的补充，不能替换原评价依据来隐藏失败。

## 论文级内核：一条承重因果链

动笔前先写出一句外行能懂的 story：现有做法把什么压扁、混在一起或留在视野之外，本文又把什么重新摊开。该句必须能指向实际证据。全文围绕这一中心认识展开，每个部分承担链条上的一环：

| 部分 | 在链条上的角色 |
|------|----------------|
| Introduction | 让读者看见这个缺口为什么存在 |
| Related Work | 说明现有 framing 为什么没有消解它 |
| Method / benchmark / data | 落实新看法的载体 |
| Experiments | 规划每类结果要回答的读者问题，并把实际结果组织成对 claim 的回答 |
| Conclusion | 留下读者应记住的认识，并说明它停在哪里 |

检验只有一条：**下一部分是上一部分的必然**。读者读完上一部分，应当自己冒出"那接下来必须回答 X"的预期，而下一部分恰好回答 X。

实验结果尚未产生时，写作思路只规定每组对比、消融、案例或分析在故事中的角色，用户决定并推动实际实验。结果产生后，所有叙述以用户提供的真实材料为边界。

## 段落级结构

- 总领句在前：首句给出本段核心观点或结论，证据、细节、推理随后展开
- 信息密度曲线"密-疏-密"：开头密（结论），中间疏（允许较长的解释句），收尾密（短句收束或过渡）
- 连接词只用来标注已经存在的逻辑关系；关系还没建立时先补内容，句子接不上不靠词接

## 常见反模式

| 反模式 | 症状 | 修复 |
|--------|------|------|
| 孤儿段 | 段落与前后无关联 | 先补因果关系，再考虑措辞（见 Bridge test） |
| 埋没主旨 | 核心观点藏在段中 | 提到段首 |
| 引用堆砌 | 一句话列10+引用 | 分类讨论，每类2-6篇 |
| 断崖过渡 | 相邻部分间无衔接 | 用一句 bridge sentence 写明已存在的关系 |
| 流水账 | 按时间线逐一描述 | 按主题/逻辑组织 |

> **Bridge test**（检测孤儿段/断崖过渡）：连续 2-3 段顺序互换是否影响阅读？能换 = 因果缺口。先回头找缺失的关系：上一段建立了什么，下一段为什么必须现在出现。关系存在而没写出来，用一句 bridge sentence 把它写明；找不到这个关系，说明至少一段没长在当前主线上，先处理它的去留和位置。

## 自查要点

- [ ] 一句话 story 可指认，每个部分能说出自己在链条上的角色
- [ ] 相邻部分满足"下一部分是上一部分的必然"
- [ ] 每段首句是总领句
- [ ] 无孤儿段、无引用堆砌
