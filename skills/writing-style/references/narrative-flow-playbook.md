# 论文叙事与段落组织

本参考用于论文级叙事和授权的结构重写。目标是让读者理解研究问题、本文的核心认识及其依据。外部章节形式遵循适用的论文体裁与 venue 要求，内容次序由当前论证决定。

真实研究会在观察、想法、实验和结果之间反复迭代。论文按成熟后的认识组织：从实际材料中确定最有价值且证据能支持的中心主张，再安排概念、相关工作、方法和结果。其余内容根据是否帮助读者理解、判断或使用这项主张决定位置与详略。

中心主张必须随证据更新。结果缩窄成立范围时，按证据和用户决定收窄 claim；结果实质推翻中心主张时，停止沿原故事润色，交用户重选主张或重构故事，并保留有实质影响的反证。后来增加的指标、数据或比较条件只能作为透明标注的补充，不能替换原评价依据来隐藏失败。

## 让各部分共同回答研究问题

先用清楚的话说明本文研究什么问题、改变了哪一点认识，以及材料如何支持它。使用项目已确认的故事；材料尚不足以支持的解释保持未决。这个概括帮助安排全文，不要求把内部规划语写进正文。

| 部分 | 对读者承担的作用 |
| --- | --- |
| Introduction | 建立研究问题及其意义，说明现有工作的具体覆盖与本文回应。 |
| Related Work | 解释本文与已有工作的关系，让差异、依据和已有贡献清楚。 |
| Method / benchmark / data | 说明解决问题或测量对象的思路、设计及必要定义。 |
| Experiments | 用实际结果回答研究问题，让观察、解释与适用范围可以区分。 |
| Conclusion | 留下本文支持的认识及其边界。 |

需要前置的定义和判断先建立，后面的分析再使用它们。共同支持一个主张的独立分析可以并列，比较与展开也可以推动论证。读者应知道一部分为何在这里、它与整体问题有什么关系；章节之间不必全部构成因果链。

实验结果尚未产生时，写作思路只规定各类结果希望回答的问题及其在文章中的作用。用户决定和推动实际实验，结果产生后按真实材料表达。用户只要求故事或写法时，不借结构整理新增实验协议、数据或结果。

## 按段落的作用展开

先判断本段在建立概念、陈述发现、解释机制、举例还是比较。读者需要先知道判断时，用总领句领起；需要通过场景、条件或推导理解判断时，先给这些内容。段落详略与句长随解释需要变化，不要求每段使用同一结构。

从读者已经理解的对象或问题引入新的信息。衔接依靠明确的内容关系；“此外”“因此”等连接词只标明已有关系。相邻段落难以衔接时，核对前段建立了什么、后段增加什么，再判断需要说明关系、移动内容、补充已有材料还是在授权范围内删去无用重复。

试着交换两段，可以帮助看出它们的依赖关系，但可交换本身不构成缺陷。两个并列分析可能顺序灵活；必须先有定义才能解释结果的两段则应保持依赖次序。不能为了固定顺序发明因果或过渡。

## 在具体问题上修正文稿

| 阅读问题 | 修改依据 |
| --- | --- |
| 读者找不到一段的重点 | 根据本段作用，把需要提前知道的对象、问题或判断写清，保留必要铺垫。 |
| 多段都在重复同一结论 | 核对每段独有的事实、证据与解释，合并无用重复，保留有不同作用的内容。 |
| 相邻部分关系不清 | 找出实际的比较、展开、条件、先后或推导关系，明确表达或调整位置。 |
| 正文按实验发生顺序流水记述 | 围绕研究问题组织结果；过程本身需要解释时保留相应顺序。 |
| 引用集中堆放，读者不知各自作用 | 按相关贡献和证据组织说明，引用随其支撑内容移动，数量由论证需要决定。 |

读完整稿后，检查读者能否复述研究问题、本文回应和证据范围，必要定义是否先于使用，各段是否承担有用作用，观察与解释是否准确，核心反证是否保留。检查针对真实问题继续修改，清楚的原段落可以保留。

衔接方法可参考 [Harvard Writing Center 的 Transitions](https://writingcenter.fas.harvard.edu/transitions)；当前论文的事实、论证与用户要求决定具体写法。
