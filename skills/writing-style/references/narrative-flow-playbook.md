# 叙事逻辑 Playbook（总分总 + 起承转合）

本 playbook 提供中文学术论文在**论文级、章节级、段落级**的叙事结构指导。

## 总分总三层嵌套

### 论文级

| 位置 | 角色 | 内容 |
|------|------|------|
| 摘要 | 总 | 全文浓缩：问题→方法→结果→意义 |
| 绪论 | 总（展开） | 背景→现状→不足→方案→贡献 |
| 第2-N章 | 分 | 各章详细内容 |
| 总结 | 总（收束） | 回顾贡献→局限→展望 |

### 章节级

| 位置 | 角色 | 内容 |
|------|------|------|
| 章首引言 | 总 | 本章目标 + 与前章衔接 |
| 各节 | 分 | 具体内容 |
| 章末小结 | 总 | 本章要点 + 向下章过渡 |

**学位论文常见要求：** 除绪论和结论外，每章需要写引言，描述本章拟完成的工作。

### 段落级

| 位置 | 角色 | 内容 |
|------|------|------|
| 首句 | 总 | 总领句（本段核心观点） |
| 中间 | 分 | 证据、细节、推理 |
| 末句 | 总 | 收束或过渡到下段 |

## 起承转合框架

### 论文级（绪论弧线）

| 步骤 | 角色 | 学术对应 |
|------|------|----------|
| 起 | 开篇 | 研究背景 + 领域现状 |
| 承 | 发展 | 现有工作详述 + 不足分析 |
| 转 | 转折 | 本文方案 + 核心思路 |
| 合 | 收束 | 贡献列表 + 结果预告 |

### 章节级（每章内部）

| 步骤 | 作用 | 实现 |
|------|------|------|
| 起 | 交代本章背景 | 引言段：本章目标+衔接 |
| 承 | 展开内容 | 各节详细阐述 |
| 转 | 关键节点 | 核心设计/关键发现 |
| 合 | 小结 | 本章要点+过渡 |

## 章节间过渡模式

| 从 → 到 | 过渡模式 |
|----------|----------|
| 绪论 → 相关工作 | "本章从以下N个方面综述相关工作。" |
| 相关工作 → 系统设计 | "基于上述分析，本章设计……" |
| 系统设计 → 实现 | "本章介绍第N章所设计系统的具体实现。" |
| 实现 → 实验 | "为验证系统的有效性，本章开展……" |
| 实验 → 总结 | "综合以上实验结果，本文……" |

更多过渡短语见 `assets/transition-phrasebank.md`。

## 段落衔接技巧

### 总领句模式

| 段落类型 | 总领句模板 |
|----------|------------|
| 观点段 | "实验结果表明，……" |
| 方法段 | "为解决上述问题，本文采用……" |
| 比较段 | "与X相比，本文方法在……" |
| 过渡段 | "上述分析表明……这促使本文……" |

### 段间衔接词

- 顺承："此外" / "进一步" / "在此基础上"
- 转折："然而" / "但" / "尽管如此"
- 因果："因此" / "由此可见" / "这表明"
- 举例："具体而言" / "以……为例"

## 段落节奏与句式变化

### 句式变化表

| 句式类型 | 适用场景 | 示例 |
|----------|----------|------|
| 主动句 | 描述本文动作 | "本文设计了……" / "本文提出……" |
| 被动/无主语句 | 描述客观现象 | "实验结果表明……" / "可以观察到……" |
| 状语前置句 | 突出条件/背景 | "在……约束下，……" / "与X相比，……" |
| 现象前置句 | 强调发现 | "值得注意的是，……" / "一个有趣的现象是，……" |

**交替使用原则**：同一段落中不连续使用 3 句以上的相同句式（如全用"本文……"开头）。

### 段落内信息密度曲线

- **开头**（密）：总领句，直接给出本段核心观点或结论
- **中间**（疏）：展开证据、细节、推理过程，允许较长的解释句
- **收尾**（密）：要点总结或承上启下，用短句收束

### 打破单调的手段

- 用"值得注意的是""一个有趣的现象是""需要指出的是"等引导句打破平铺直叙
- 在连续方法描述中插入一句简短的设计动机（"之所以选择……是因为……"）
- 在连续数据报告中插入一句解读（"这一差距可能源于……"）

## 常见反模式

| 反模式 | 症状 | 修复 |
|--------|------|------|
| 孤儿段 | 段落与前后无关联 | 加过渡句 |
| 埋没主旨 | 核心观点藏在段中 | 提到段首 |
| 引用堆砌 | 一句话列10+引用 | 分类讨论，每类2-6篇 |
| 断崖过渡 | 章节间无衔接 | 章首引言 + 章末小结 |
| 流水账 | 按时间线逐一描述 | 按主题/逻辑组织 |

> **Bridge test**（检测孤儿段/断崖过渡）：连续 2-3 段顺序互换是否影响阅读？能换 = 缺 bridge sentence（每段末句应承接下段开头）。

## 自查要点

- [ ] 每章有引言段（除绪论和结论）
- [ ] 每段首句是总领句
- [ ] 章节间有过渡
- [ ] 无孤儿段
- [ ] 无引用堆砌
- [ ] 整体遵循总分总
